# HomeyLab
My attempt at making a home lab alongside a network refresher and hacking testing ground, let's see how long I stick to this before I get lazy. 

First Order of Business- 
  1. Mostly to refresh myself on networking basics. That's why I'll be making a small business based network with several "servers" and setting up their firewalls, sub nets, communications, etc.
  2. For some ethical hacking practice, I'll be attempting various types of attacks to gain an understanding of how to intrude on systems, what to look out for, etc.
  3. Hopefully make this into an actual home lab for my own personal amusement because I like the idea of having something cool like this
